# lab
Continuous learning, training and practice. Everything I experiment with and can be useful for myself and others is here

## Projects
### Pomodoro API

FastAPI service for creating, listing, completing, and interrupting Pomodoro sessions, with PostgreSQL (Alembic) and Docker.

See [pomodoro-api/README.md](pomodoro-api/README.md) for setup, environment variables, API usage, tests, and Docker.

### Restic

Restic is a modern backup program that is fast, efficient, and secure. This section serves as a template and guide for setting up restic backups on Linux.

See [restic/README.md](restic/README.md) for detailed documentation and setup instructions.

### PostgreSQL

A Docker-based PostgreSQL practice environment for learning database administration skills relevant to the LPIC-1 Linux certification. Covers configuration, user management, backups, and monitoring.

See [postgres/README.md](postgres/README.md) for the practice guide and exercises.
